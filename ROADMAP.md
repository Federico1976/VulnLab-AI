# Roadmap

## Phase A - Completed

Universal Runtime Modeling Foundation v1.0.

Status: frozen.

## Final Architectural Validation

- Xamarin / .NET MAUI
- NativeScript

## Phase B - Intelligence Layer

### 1. Dynamic Confidence Learning

Move from static confidence weights to confidence updated by real validation outcomes.

### 2. Causal Reachability

Move from predicted reachability to proven reachability using:

- Joern
- Call Graph
- Data Flow
- Propagation Graph

### 3. Reasoning Engine

The LLM will reason over:

- Runtime Ontology
- Evidence Graph
- Reachability Graph
- Dynamic Validation Plan
- Responsible Disclosure Candidate

The LLM should not read millions of raw code lines directly.
