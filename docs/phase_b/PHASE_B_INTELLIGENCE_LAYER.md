# Phase B - Intelligence Layer

Phase B turns VulnLab-AI from a universal runtime modeling engine into a learning and reasoning APK hunting agent.

## Core Objectives

1. Dynamic Confidence Learning
2. Causal Reachability
3. Graph-based Reasoning Engine

## Principle

The LLM must not read raw code as its primary input.

It must reason over structured artifacts:

Runtime Ontology
→ Evidence Graph
→ Reachability Graph
→ Dynamic Validation Plan
→ Responsible Disclosure Candidate

## Goal

Move from static candidate scoring to adaptive, evidence-driven, validation-aware reasoning.
