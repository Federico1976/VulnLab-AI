# Contributing

VulnLab-AI is focused on defensive Android APK security research and responsible disclosure.

## Contribution Rules

- Do not add target-specific detectors.
- Do not hardcode APK names, package names, vendors, or bug bounty targets.
- Every contribution must improve universal reasoning.
- Every candidate must preserve evidence.
- Do not label a candidate as a vulnerability without reachability and validation.
- Prefer semantic modeling over signature matching.

## Research Scope

Accepted work includes:

- runtime modeling
- semantic bridge extraction
- evidence graph improvements
- reachability analysis
- dynamic validation planning
- responsible disclosure automation

Out of scope:

- exploitation against unauthorized targets
- destructive testing
- credential theft
- DoS logic
- target-specific bypasses
